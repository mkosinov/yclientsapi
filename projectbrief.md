# YClients API - Project Brief

## Project Overview
YClients API is a Python library for interacting with the YClients REST API. The library provides a clean, type-safe interface for managing salon and beauty business operations including appointments, services, staff, and more.

## Core Objectives
- Provide a comprehensive Python SDK for YClients API
- Implement proper error handling and logging
- Ensure type safety throughout the codebase
- Maintain high code quality with comprehensive testing
- Follow Python best practices and modern development standards

## Technical Stack
- **Language**: Python 3.8+
- **Package Manager**: Poetry
- **Linting**: Ruff
- **Testing**: pytest
- **Documentation**: Sphinx (planned)

## Key Features
- Authentication management
- CRUD operations for all YClients entities
- Comprehensive error handling
- Type hints throughout
- Integration testing suite

## Architecture Principles
- Clean separation of concerns
- Modular component design
- Consistent error handling patterns
- Comprehensive logging and monitoring
- Type safety as a first-class concern

## Development Standards
- Follow PEP 8 and modern Python conventions
- Use type hints for all public APIs
- Implement comprehensive test coverage
- Maintain backward compatibility
- Document all public interfaces
